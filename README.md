# 1C-HW

Репозиторий с домашними работами и отчетами по самостоятельному изучению 1С. Материалы описывают выполненные задания, настройки конфигурации и результаты работы в формате Word и Markdown.

## Содержимое

- `README_1.md` — задание по созданию справочника «Сотрудники».
- `README_2.md` — описание следующего задания по 1С.
- `README_3.md` — описание третьего задания по 1С.
- `Отчет_по_1С_ДЗ1.docx` — отчет по первому заданию.
- `Отчет_Начисление_зарплаты_1С.docx` — отчет по начислению зарплаты.
- `Отчет_Фонд_оплаты_труда_1С.docx` — отчет по фонду оплаты труда.

## Темы работ

- создание справочников в 1С;
- настройка реквизитов и форм;
- работа с кадровыми и расчетными данными;
- оформление отчетов по выполненным заданиям.

## Назначение

Репозиторий помогает хранить учебные материалы по 1С в одном месте и быстро находить отчеты по каждому заданию.
